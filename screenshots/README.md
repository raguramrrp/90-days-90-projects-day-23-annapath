# ANNAPATH — Screenshots & Interface Guide

This directory holds visual demonstration screenshots of the running **ANNAPATH** platform.

---

## 📸 Recommended Capture Sequence

Run the application locally via `run.bat` and capture the following five views:

### 1. `01_recipient_discovery_map.png`
- **Route:** `http://127.0.0.1:8000` (Recipient Persona)
- **View:** Toggle **Map View** on the Discover tab showing OpenStreetMap pins across Bengaluru with available portion badges (`₹0 FREE`, `28 left`).

### 2. `02_recipient_reserve_modal.png`
- **Route:** Click **Reserve Portions** on any card.
- **View:** Shows portion selector counter, direct pickup vs. volunteer delivery radio cards, and FSSAI hygiene confirmation.

### 3. `03_recipient_active_otp.png`
- **Route:** **My Reservations** tab.
- **View:** Prominently highlights the dark emerald card with the **6-Digit Collection OTP** (e.g., `842109`) and collection status tracker.

### 4. `04_hotel_counter_otp_desk.png`
- **Route:** Switch persona to **Hotel Staff**.
- **View:** Shows the active listings table and the **Counter OTP Verification Desk** where staff inputs the recipient OTP to authorize handover.

### 5. `05_volunteer_delivery_stepper.png`
- **Route:** Switch persona to **Volunteer**.
- **View:** Shows the active delivery mission card with the 3-step live stepper (Reached Hotel → Packages Collected → Doorstep OTP Verification).

### 6. `06_sustainability_impact_dashboard.png`
- **Route:** Switch persona to **Admin** or click **Platform Impact**.
- **View:** Shows total meals delivered, kg food waste avoided, CO2e emissions prevented, and the city-wise Recharts bar chart.
